The Project

About

A portfolio project at the intersection of a genuine love for baseball and the challenge of building real web applications.

Why I Built This

Baseball has a unique relationship with data — no other sport has been so deeply analyzed, so obsessively documented, or so thoroughly transformed by analytics. I wanted to build something that honors that tradition while teaching myself the fundamentals of full-stack web development.

This project started as a simple multi-page Flask site and evolved into a data-driven application with search, dynamic templates, and a JSON-driven backend. Every feature was a new lesson.

Tech Stack

Python 3 Flask Jinja2 HTML5 CSS3 JSON Git / GitHub

What I Learned

Flask routing — serving multiple pages from a single Python app Jinja2 template inheritance — keeping HTML DRY with base layouts and blocks Dynamic content rendering — loading and filtering JSON data per request Search with query params — using request.args to filter data server-side CSS architecture — variables, responsive grids, and animations without a framework Version control workflow — meaningful commits, structured branching Local development — debugging Flask dev server, static file paths, port conflicts

What's Next

The roadmap includes integrating a live API (MLB Stats API or Baseball Reference) to replace static JSON data, adding individual player detail pages, and eventually deploying to a public URL so this lives on a real server — not just localhost.
