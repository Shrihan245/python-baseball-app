# Python Baseball Web App

A multi-page web application built using Python and Flask that showcases
baseball players and teams while demonstrating backend routing,
template inheritance, and dynamic data rendering.

## Features
- Multi-page Flask application
- Player and team pages
- JSON-driven dynamic content
- Search functionality
- Responsive layout with custom CSS

## Tech Stack
- Python
- Flask
- HTML / CSS
- Git & GitHub

## Run Locally
```bash
pip install -r requirements.txt
python app.py

Open:
http://127.0.0.1:5000/
